# Multiplayer FPS

Fast-paced multiplayer first-person shooter made in Godot Engine.

## Project Status

Under development

## Features

### Minimal Viable Product

- [ ] Advanced player movement system
- [ ] Shooting and reloading a gun
- [ ] Only one playable gun (pistol with 7 shots in a magazine) with a placeholder model and animations
- [ ] Client-Server multiplayer connection
- [ ] Health system
- [ ] Basic player model and animations
- [ ] Main menu placeholder
- [ ] Waiting lobby placeholder
- [ ] In-game scoreboard
- [ ] After-match scoreboard and lobby
- [ ] Basic map
- [ ] VoIP

### Full Release

- [ ] All base guns: pistol (already implemented), assault rifle, shotgun
- [ ] Special weapons (one hit one kill): banana pistol, knife
- [ ] Weapon randomizer system (every 2 kills, or one kill with special weapon, player gets a different weapon)
- [ ] Final models and animations for all weapons
- [ ] Final player model and animations
- [ ] Final models for environment
- [ ] Final UI design

## Requirements

- Godot Engine 4.7

## How to clone

Clone the repository:

```bash
git clone https://github.com/naxemis/multiplayer-fps.git
cd multiplayer-fps
```
